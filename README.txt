SP INDUSTRIAL FILTRATION — WEBSITE STAGE 1

Included files:
- index.html: main website page
- styles.css: responsive design
- script.js: mobile menu, product search/category filters, enquiry email preparation

Preview:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Firefox or another modern browser.
3. To edit the website, open the folder in VS Code or another text editor.

Before publishing:
1. Replace YOUR-EMAIL@example.com in script.js with the real company enquiry email.
2. Add a real phone number and confirm the location text in index.html.
3. Confirm which products you can actually manufacture or supply, their specifications and any quality/certification claims.
4. Replace the CSS illustrations with real product photos when available.
5. Test the form. It prepares an email in the visitor's email application; it does not store or send data on a server.
6. Buy a domain and hosting later, then upload the three website files to the hosting web root.

This is a static HTML/CSS/JavaScript starter website. It is not yet online and includes no domain or hosting.
